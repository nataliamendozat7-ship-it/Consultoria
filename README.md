# Marathon Vitamin Shop — Página web académica

Versión ampliada del proyecto de e-commerce.

## Funciones
- Carrusel automático de 3 publicidades con imágenes creadas para el proyecto.
- Catálogo con 14 productos y fotografía individual.
- Descripción breve, calificación y número de reseñas.
- Distintivo “Más pedido” en productos con mayor demanda de demostración.
- Búsqueda y filtro por categoría.
- Crear cuenta e iniciar sesión con `localStorage`.
- Carrito con cantidades y eliminación.
- Cupones funcionales dentro de la demostración: **MVS10** aplica 10% de descuento.
- Descuento automático del 10% en compras de $1,500 MXN o más.
- Checkout con tarjeta de crédito/débito, PayPal, Mercado Pago, transferencia, OXXO y pago contra entrega (todos son métodos simulados; no se realiza ningún cobro).
- Generación automática de código único de seguimiento al confirmar un pedido.
- Rastreo dentro de la página pegando el código del pedido.
- Seguimiento visual por etapas.
- Diseño adaptable a computadora y celular.

## Ejecutar
Abre `index.html` en Chrome o Edge. No requiere compilación.

## Cupón de prueba
Crea una cuenta, agrega productos al carrito y en el checkout escribe **MVS10** y pulsa “Aplicar”.
